# Cara ganti gambar di situs ini

Taruh file JPG/PNG di folder ini dengan NAMA FILE PERSIS seperti daftar di
bawah, timpa (overwrite) file lama kalau sudah ada. Halaman otomatis
menampilkan gambar barunya — tidak perlu edit HTML atau CSS sama sekali.

| Nama file yang harus dipakai | Dipakai di mana                                   | Ukuran disarankan          |
|-------------------------------|----------------------------------------------------|-----------------------------|
| hero-banner.jpg                | Background besar di section 1 (paling atas) homepage | min. 1600x1000px, JPG, <400KB |
| trust-photo.jpg                | Foto armada & teknisi (homepage, section "Transparansi Layanan") | min. 800x600px (4:3), JPG, <300KB |
| tim-pendiri.jpg                | Foto tim & pendiri (halaman "Tentang Kami")          | min. 800x600px (4:3), JPG, <300KB |
| og-cover.jpg                   | Gambar preview saat link di-share ke WhatsApp/Facebook | 1200x630px, JPG, <300KB     |
| favicon.ico                    | Ikon kecil di tab browser                            | 32x32px atau 64x64px, .ico  |

Kalau salah satu file belum ada / belum ditaruh, halaman tetap tampil normal
pakai placeholder bawaan — jadi aman, tidak akan error atau rusak tampilannya.
Tinggal drop file-nya kapan saja fotonya sudah siap.
